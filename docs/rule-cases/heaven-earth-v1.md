# 天地盘 v1 已审阅规则案例

本规则只使用历法阶段的生效月将与生效占时。地盘固定按 `子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥` 排列；令月将加临占时所在的地盘宫，再依此顺序将天盘顺布。

## 公式与传统方位

令 `g` 为月将支在十二支序列中的索引，`h` 为占时支索引。转位数为：

`offset = (g - h + 12) % 12`

对每一个地盘支 `earth`（索引为 `e`），天盘支为：

`heaven = EARTHLY_BRANCHES[(e + offset) % 12]`

因此占时宫必定承接月将，即 `palace[占时].heaven = 月将`。地盘传统方位为：子北、丑寅东北、卯东、辰巳东南、午南、未申西南、酉西、戌亥西北。方位只说明固定地盘位置，不改变上述以十二支正序进行的顺布。
