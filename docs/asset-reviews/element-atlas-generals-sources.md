## 校勘与使用边界

- 《六壬-天将详解》天后小节出现“前一家”，但该笔记总序与整套顺序不符。本组正文不引用该处方位断句，只用无矛盾的家位、角色和类象；未修改用户知识库。
- 《五行-释名》金条出现“土生于金”，与《五行-相生》及既有程序关系不符。正文采用相生篇明确的“土生金”，不转述疑似笔误；未修改用户知识库。
- “来历”栏目说明所读材料如何建立概念和角色类比，不把职官比喻、雷部描述或神祇名称编造成可考的神话起源。
- 古籍有关鬼祟、疾病、生死、刑狱、婚姻操守的断语均不当作事实结论或现代决策建议。职业、性别与亲属等级的旧式分类仅作历史解释。
- 所有取象属于传统理解。五行是本工具采用的分类关系，不声称具有现代科学因果证明；各条不保证吉凶。
- 仅给图片文件名与裁切位置。图片版权和实物身份由本轮总素材审查记录负责；本文不声称绘画中的鸟、龙、虎就是对应的六壬天将。玄武用 `waterfall.jpg` 的水意象，不新增龟类图。
