# 网站三维清晰度优化

目标网站：https://wangrufan-frank.github.io/design-daliuren/ 。2026-09-12 读取其 HTML 与 index-RK8zNZOE.js，确认使用完整版 GLB 加载器。修改基于 e8c4cf5，工作区为 publish-element-atlas；尚未提交或发布。

## 修改

- 使用实际画布宽高计算像素预算，最高 DPR 3、400 万渲染像素；取代手机固定 DPR 1.5 上限。
- 模型 LOD 继续按屏幕宽度选择，取消高 DPR 导致桌面使用更低精度模型的条件。手机仍保留 LOD2 和原有超时备用模型。
- 加载后的材质贴图启用最高 8 倍各向异性过滤，以设备支持值为限，兼容多材质网格，环境贴图除外。

## 限制

提高分辨率增加 GPU 负担，400 万像素预算仅为上限控制，不等于所有手机都能保持同一帧率。资源本身的细节上限仍然存在，未用插值放大冒充新增纹饰。此次没有更换模型、修改历法规则或小程序。
