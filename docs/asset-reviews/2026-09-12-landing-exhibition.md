# 器物展览式首页介绍

按确认方案，将线框圆占位图替换为现有玉盘的完整斜俯视实景。改用 LOD0 模型直接渲染的 2400×1800 WebP 独立图片，移除整页截图和放大裁切样式。首页不加载 WebGL。图片按 BASE_URL 引用，支持 GitHub Pages 子路径。

主标题“大六壬演式”，副标题“观器物之形 / 读课式之序”，三项功能采用“观、读、溯”及具体说明。配色延续青绿、米白、浅金，窄屏上图下文，手机功能说明单列。修改仅限介绍组件、对应样式和静态资源。

验证：App 首页介绍和提交生成相关 2 项测试通过，生产构建通过；390px 浏览器宽度无横向溢出，图片自然宽度 2400，功能列宽 308.667px。电脑视觉预览位于根工作区 output/landing-exhibition-review。手机截图工具有缩放现象，布局以 DOM 尺寸检查为准。
