# 玉石质感与光影优化

基于已发布的 bb33333；验证时尚未提交或发布。

用户选择玉石质感与光影方向，保留浅玉色、文字可读性和现有盘面结构。

- 环境强度 0.9 → 0.65，半球补光 1.05 → 0.65，主光从侧上方照射，主光强度 1.65 → 2。
- 一盏主光启用 2048² PCF 阴影，阴影强度 0.45，近距离阴影相机覆盖盘体；文字、交互环、推演线不参与阴影。地面接收阴影。
- 外盘原有法线贴图强度约 0.24 → 0.4，粗糙度约 0.31 → 0.35；将环玉材质粗糙度 0.27 → 0.32，清漆反射保持克制。
- 退出场景时释放主光阴影资源；未新增图像资源或修改模型几何。
