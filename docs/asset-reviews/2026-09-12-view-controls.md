# 三维取景与查看按钮

基于已发布 45c7a47；验证时尚未提交或发布。用户确认默认完整取景，增加整体、俯视、细节视角及放大、缩小、复位按钮。

实现：按盘体包围盒八角在镜头横纵视场中的投影计算整体距离，预留边缘；整体采用居中斜视，俯视接近垂直，细节为更近距离。按钮缩放限定为整体基准的 0.35—2 倍距离，复位回整体。恢复旧阶段镜头时同步恢复其投影设置。按钮放于画布外，窄屏三列两行，最小点按高度 44px。

验证：完整取景测试先复现缺失功能后通过，覆盖横屏与竖屏包围盒角点、缩放、复位和俯视。控制器专项 5 项、页面专项 3 项通过。npm run build、git diff --check 通过。浏览器中逐个操作三种视角、放大、缩小和复位；390px 宽度模拟按钮约 102×44px，无页面横向溢出。测试未覆盖手机真机性能；未重跑已知存在基线问题的全套测试。
