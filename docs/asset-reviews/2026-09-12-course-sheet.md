# 文字课式阅读优化

按用户确认的方案，将网站 CourseSheet 重排为本课、十二宫、四课、三传，DOM 顺序与视觉顺序一致。手机四课保持从左到右四、三、二、一的四列；突出四柱，分组显示本课信息；十二宫使用统一图例，天盘字与神将同字号，地盘保持原字号。移除内部阶段说明文案。

导出区域仅含四部分课式正文，保存按钮及预览位于其外，防止重复导出留下预览区域高度。实测发现桌面居中外边距会造成图片裁切，导出副本将 margin 设为 0 后重新生成图片，十二宫和四课右侧均完整。

验证：CourseSheet.test.tsx 与 CourseSheet.atlas.test.tsx 共 10 项通过；npm run build 通过（既有 chunk 大小提醒仍存在）；320px、390px 浏览器布局无横向溢出，四课顶坐标一致。实际导出的电脑、手机图片位于根工作区 output/course-sheet-review。

后续阅读提示：四柱标注年、月、日、时；四课增加上下层图例；三传增加与数据对齐的四列表头。旬空标记在文字课式内统一为 10px，窄屏宫格行高调整为 1.1。320px 实测三传表头和各行列起点一致，页面无横向溢出。
