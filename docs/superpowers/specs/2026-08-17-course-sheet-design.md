# 标准文字课式与纯文本复制设计

## 1. 目标

完成规则链第 6 阶段“复制结课”：把已经验证的历法、天地盘、四课、三传和天将结果投影为独立、不可变、可重算校验的 `course` 快照，并用同一份结构化结果呈现标准文字课式和生成可复制的纯文本。

本阶段闭合当前规则链，但不增加新的术数推导。

## 2. 已确认口径

- `course` 是已有事实的最终投影，不是新的传统规则计算层；
- 标准课式展示三传阶段已经验证的六亲、取法、子类和变体，但不重新计算这些字段；
- 不计算或展示遁干、神煞、尚未由上游生成的课体格局或断语；
- 复制格式采用适合微信和记事本的纯文本分段，不采用 Markdown 表格；
- 桌面版采用“课案双栏”；
- 右栏必须复用既有十二宫 4×4 围合方盘，不得退化成 3×4 清单；
- 三传按初传、中传、末传纵向排列；
- 四课按四课、三课、二课、一课排列；
- 四课和三传内部的首要读取顺序为“天将 → 传/课标签 → 支神”；
- 暂不实现三维复制课式、图片导出和打印。

## 3. 范围

### 3.1 本阶段包含

- 真实 `course` 领域结果、快照、阶段运行器和错误契约；
- 从所有有效上游生成规范化课式；
- 结构守卫与基于真实上游的 canonical 重算守卫；
- 标准文字课式页面；
- 稳定的纯文本序列化函数；
- 剪贴板复制成功和失败反馈；
- 最终阶段轨道状态与全部已完成阶段的回看导航；
- 单元、组件、会话、端到端和离线测试；
- 一份课式字段到上游结果及回归测试的追溯清单。

### 3.2 本阶段不包含

- 六亲、三传取法、子类或变体的重新推导；
- 遁干、神煞、额外课体格局、断语或吉凶解释；
- 人工编辑、人工批准或部分课式；
- Markdown 复制；
- 三维模型、复制动画、图片导出或打印；
- 保存到账号、云端或外部应用。

## 4. 架构选择

采用独立结构化 `course` 快照。页面模型和纯文本分别是该快照的纯投影，不把 HTML、CSS 或最终复制字符串写入领域结果。

```text
calendar ───────────────────────────┐
four-lessons ───────────────────────┤
three-transmissions ────────────────┼─> course ─┬─> 标准文字课式
heavenly-generals ──────────────────┘          └─> 纯文本

heaven-earth ─> four-lessons / three-transmissions / heavenly-generals
```

`course` 的直接快照依赖固定为：

```ts
["calendar", "four-lessons", "three-transmissions", "heavenly-generals"]
```

天地盘是传递依赖。课式中的十二宫直接读取天将结果内已经闭合的地盘、天盘和天将记录；阶段运行器仍按真实顺序验证完整的历法、天地盘、四课、三传和天将链条。

规则编号使用版本化白名单值：

```text
course/verified-projection-v1
```

## 5. 领域结果

`CourseResult` 按用途分组，不保留现有测试夹具中的布局占位字段。

### 5.1 `context`

- 民用北京时间；
- 生效干支日期；
- 地点名称；
- 农历显示文本；
- 生效年、月、日、时四柱；
- 月建；
- 月将名称与地支；
- 生效占时地支。

地点名称来自已提交的起课输入，其余字段来自有效历法快照。

### 5.2 `method`

- 三传取法；
- 可选子类；
- 零个或多个变体。

这些字段逐字读取三传快照，不在课式阶段重算。

### 5.3 `transmissions`

固定为初传、中传、末传三条，每条包含：

- 位置和标签；
- 支神；
- 六亲；
- 所乘天将。

支神和六亲来自三传结果；天将通过同一份天将结果按天盘支神查询。

### 5.4 `lessons`

固定按四、三、二、一的视觉顺序保存，每条包含：

- 课 ID 与标签；
- 上神；
- 下神种类和值；
- 所乘天将。

上下神来自四课结果；天将通过四课上神查询天将结果。不得修改四课快照或向其中加入天将字段。

### 5.5 `palaces`

固定按现有方盘视觉顺序保存十二条记录，每条包含：

- 地盘宫；
- 天盘支神；
- 天将；
- 是否为贵人宫。

所有字段来自天将布列结果。同一地盘、天盘和天将必须各自唯一且完整。

### 5.6 `noble`

- 昼占或夜占；
- 贵人所乘天盘支；
- 贵人所临地盘宫；
- 顺布或逆布。

这些字段逐字读取天将结果。

## 6. 生成流程

纯函数 `deriveCourse` 接收起课地点名称和已验证的历法、四课、三传、天将结果：

1. 规范化历法上下文；
2. 复制三传取法、子类和变体；
3. 按初、中、末构建三传，并按支神查询天将；
4. 按四、三、二、一构建四课，并按上神查询天将；
5. 按既有十二宫视觉顺序复制宫位记录；
6. 复制贵人摘要；
7. 返回字段顺序稳定的不可变结果。

任何天将查询失败、条目缺失或重复都立即失败，不输出部分结果。

相同输入重复生成必须产生逐字节相同的领域结果和纯文本。

## 7. 快照来源与守卫

当任一直接依赖快照来源为 `manual` 时，课式快照来源为 `manual`；否则为 `automatic`。

守卫分两层：

1. 结构守卫检查精确字段、枚举、数量、标签顺序、唯一性和禁止的额外字段；
2. canonical 守卫使用真实起课输入和上游快照重新运行 `deriveCourse`，逐项比较完整结果。

以下篡改必须失败：

- 时间、地点、农历、任一四柱、月建、月将或占时错误；
- 取法、子类、变体、六亲或三传支神错误；
- 四课顺序、上神、下神种类或下神值错误；
- 任一三传或四课所乘天将错误；
- 宫位缺失、重复、顺序错误或天地将映射错误；
- 贵人所乘支、落宫、昼夜或顺逆错误；
- 合法规则编号、依赖或来源值放在错误位置；
- 结构合法但不符合当前上游的旧课式。

## 8. 阶段运行与失效

应用在天将阶段成功后自动运行 `runCourseStage`：

1. 按历法、天地盘、四课、三传、天将的顺序验证上游；
2. 构建课式候选结果；
3. 执行结构和 canonical 守卫；
4. 移除旧课式并写入新快照；
5. 选择标准文字课式页面。

失败结果使用稳定错误码，并携带可定位的上游阶段字段：

- 上游缺失或无效；
- 天将映射不完整；
- 课式结果不完整；
- 课式守卫失败。

失效规则：

- 上游无效时，从最早无效阶段清除后续快照，只保留此前有效结果；
- 课式投影或守卫失败时，只清除 `course`，保留完整五阶段结果；
- 失败页面回到天将审校，阶段轨道显示“复制结课，进行中”；
- 不生成部分课式、空白占位或伪造回退。

## 9. 标准文字课式页面

页面只消费经过 canonical 验证的课式结果，不读取其他快照临时补字段，也不在 React 中重算术数规则。

### 9.1 桌面布局

1. 页首：标题、地点、北京时间、农历和四柱；
2. 主体为接近等权的课案双栏；
3. 左栏先显示纵向三传，再显示四课；
4. 右栏显示既有 4×4 围合十二宫方盘；
5. 中宫显示月将、占时、贵人和顺逆摘要；
6. 底部显示复制说明和“复制课式”按钮。

三传按初、中、末纵排。四课按四、三、二、一横排。三传与四课内部均先显示天将，再显示标签与支神；三传同时显示六亲，取法、子类和变体放在三传摘要中。

方盘沿用现有方位语义：上南、下北、左东、右西。十二宫环列，中宫留空承载摘要，不使用 3×4 清单替代。

### 9.2 移动端

移动端按以下顺序单列：

```text
摘要 → 三传 → 四课 → 十二宫 → 复制
```

方盘空间结构保持不变，页面不得产生横向溢出。四课允许在窄屏调整列数，但不得改变四、三、二、一的内容顺序或天将优先层级。

### 9.3 回看导航

课式生成成功后，六个阶段全部标记为“已完成”。阶段轨道允许没有“进行中”节点；课式本身是可回看的已完成按钮，并用 `aria-current="page"` 标记当前页面。

用户可以在任一完成阶段之间导航，不触发重算。

## 10. 纯文本复制

纯函数 `serializeCourseText` 只接收 `CourseResult`，使用固定 LF 换行和固定分段顺序：

```text
大六壬标准课式
时间：{civilDateTime}
地点：{locationName}
农历：{lunarDateDisplay}
四柱：{yearPillar}　{monthPillar}　{dayPillar}　{hourPillar}
月建：{monthBuild}
月将：{monthGeneralName}（{monthGeneralBranch}）　占时：{divinationHour}

三传取法：{method}[ · {subtype}][ · {variant1}/{variant2}]
初传：{general}　{branch}　{relation}
中传：{general}　{branch}　{relation}
末传：{general}　{branch}　{relation}

四课
四课：{general}　上神{upper}　下神{lower}
三课：{general}　上神{upper}　下神{lower}
二课：{general}　上神{upper}　下神{lower}
一课：{general}　上神{upper}　下神{lower}

十二宫
{earth}宫：{general}　天盘{heaven}　地盘{earth}
（其余十一宫按既有方盘视觉顺序逐行输出）

贵人：{dayNight}贵{nobleHeaven}　落{nobleEarth}宫　{direction}布
```

花括号表示字段插值，不进入最终文本；方括号表示整个可选片段。子类存在时以 ` · ` 追加，变体存在时再以 ` · ` 追加并使用 `/` 连接多个变体；不存在的可选片段完全省略。十二宫必须输出十二行，顺序与课式结果一致。

点击“复制课式”后调用剪贴板写入：

- 成功时按钮短暂显示“已复制”，并通过非打断式状态文本通知；
- 失败时按钮保持可再次操作，显示可访问错误提示；
- 复制成功或失败都不得修改会话和快照；
- 页面离线后仍可生成和复制文本。

## 11. 测试矩阵

### 11.1 领域投影

- 固定参考课例精确验证全部上下文字段；
- 取法、可选子类、变体和三传六亲逐字继承；
- 三传按初、中、末，四课按四、三、二、一；
- 三传与四课天将查询正确；
- 十二宫视觉顺序、天地将映射和贵人标记正确；
- 相同输入的结果和纯文本稳定；
- 子类或变体缺省时不产生占位。

### 11.2 守卫与会话

- 缺字段、额外字段、错误枚举、错误数量和重复条目；
- 逐类篡改历法、取法、六亲、课传、天将、宫位和贵人摘要；
- 结构合法但与实际上游不一致；
- 任一真实上游缺失或无效；
- 每条失败路径只保留有效上游；
- 任一人工修正向课式来源传播；
- 上游重算清除旧课式。

### 11.3 页面与复制

- 三传纵排；
- 天将在三传和四课 DOM 读取顺序中先于标签与支神；
- 十二宫为 4×4 围合布局且中宫摘要存在；
- 桌面左右接近等权；
- 移动端顺序正确且无横向溢出；
- 取法、子类、变体和六亲可见；
- 复制输出逐行精确匹配；
- 剪贴板成功、失败、重复点击和状态反馈正确；
- 不显示遁干、神煞、未验证格局或断语。

### 11.4 应用与端到端

- 从输入自动运行至标准文字课式；
- 离线状态下完成六阶段并复制文本；
- 六个阶段全部显示已完成，且不存在虚假的进行中节点；
- 可返回天将、三传、四课、天地盘和历法，再返回课式；
- 修改历法修正后旧课式失效并使用新上游重建；
- 390×844 无横向溢出；
- 原五阶段审校、焦点和回看测试不退化。

## 12. 追溯文档

新增 `docs/rule-cases/course-v1.md`，把每个课式字段组映射到唯一上游结果和现有回归测试。该文档明确说明：课式阶段没有新的传统规则来源，所有术数事实的权威证据仍位于其原始阶段。

## 13. 完成标准

只有同时满足以下条件才算完成：

- `course` 是真实、独立、可重算验证的快照；
- 页面和复制文本只读取同一份课式结果；
- 所有可见术数字段都能追溯到已验证上游；
- canonical 守卫能拒绝结构合法但语义错误的课式；
- 已批准的课案双栏、三传纵排、天将优先和十二宫围合布局落实；
- 纯文本在常见消息和记事应用中保持稳定分段；
- 六阶段完成状态、失败保留范围和回看导航正确；
- 全量单元测试、构建、端到端测试和差异检查通过；
- 没有实现本阶段明确排除的规则、三维或导出功能。
