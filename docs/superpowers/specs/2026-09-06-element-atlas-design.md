# 元素图鉴首批设计

用户已确认：网站与小红书工具同步提供中国古画/文物风格的元素解释卡片，包含来源历史、背景、传统含义及本课位置。第 2、3 项更新保持独立，本轮不实施。

## 本轮交付

首批五个条目：子、亥、贵人、天地盘、空亡。共享离线知识、图片和 React 卡片。图鉴入口在起课前与结果页均可使用；已覆盖文字元素可直接打开卡片。盘面单击打开对应条目，拖动/缩放不误触。未覆盖元素不提供虚假解释。

卡片采用古画大图与清晰展签正文，上部名称及一句解释，下部按需展开来历、六壬含义、常见误解和来源。当前课式作为独立区块，读取 CourseResult，不另写排盘算法。子亥可对照；不硬套大河/小溪，配图为意象而非考据证据。

图片优先使用已核实开放授权的馆藏图，保留作品/机构/许可；详细下载来源保存在资产清单，离线界面显示文字来源。手机底部阅读层，桌面侧边阅读层；关闭恢复触发焦点与盘面，支持 Escape、键盘焦点约束及减少动态效果。

## 约束与验证

- 小工具不联网，不引入外部 URL、WASM 或新依赖，兼容现有 Chrome 61 / ES2017 构建，ZIP 不超过 10 MiB。
- 图片资源不转 Base64，按需解码。首批图片总量目标小于 1 MiB。
- 不修改历法/取传/神将规则、模型几何、已有旋转机制。共享卡片打开时不得重建模型。
- 知识卡保存为图片沿用小工具桥接能力，网站提供图片预览；本轮不增加账号、同步或 AI。
- 单元验证：关闭/返回/焦点、对照、课式切换更新、未知元素、资源失败。
- 构建两端，检查小工具离线资源和 ZIP；浏览器核对桌面和手机版、图片、排盘后状态以及无横向溢出。真机容器未经实测须明确说明。
