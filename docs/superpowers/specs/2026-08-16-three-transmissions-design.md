# 三传取法设计

日期：2026-08-16
状态：已确认，待编写实施计划

## 1. 目标与范围

第四阶段在已生效的天地盘和四课基础上，依照林烽《大六壬详解》第三章第一节“九宗门”确定初传、中传、末传，并为每一传标注六亲。

本阶段覆盖：

- 贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、反吟九宗门；
- 始入、元首、重审、知一、见机、察微、缀瑕（复等）、蒿矢、弹射、虎视、冬蛇掩目、不虞、自任、自信、杜传、井栏等细分课格；
- 初传筛选、中末传递取或专法推导；
- 三传六亲；
- 可逐步审阅的结构化取法证据；
- 快照校验、上游变更失效及失败时的下游清理。

本阶段不覆盖：

- 十二天将加临；
- 最终课体综合判断；
- 三传手工改写或人工批准。

规范用语采用书中的“反吟”；“返吟”只可作为搜索或说明别名，不作为结果枚举值。

## 2. 成功标准

1. 任一有效天地盘与四课输入只能得到一个确定的九宗门结果，或得到带完整候选上下文的明确失败。
2. 输出固定包含初传、中传、末传、每传六亲、主课格、细分课格和完整证据。
3. 伏吟、反吟先于普通规则识别，且只在各自专法内继续推导。
4. 林烽书中课例能够作为固定回归样本通过。
5. 篡改主课格、三传顺序、六亲或关键证据的快照不能通过校验。
6. 计算失败保留日历、天地盘、四课，清除三传及所有下游快照。
7. 单元测试、构建和浏览器回归全部通过。

## 3. 上游依赖与阶段接线

现有阶段表把 `three-transmissions` 仅声明为依赖 `four-lessons`，不足以支撑九宗门计算。三传还会直接读取完整天地盘，用于：

- 判断伏吟和反吟；
- 查询某地盘宫的上神或某天盘神所临地盘；
- 普通中末传递取；
- 涉害从当前加临宫归本家；
- 昴星从酉位取用。

因此三传的直接依赖调整为：

```text
three-transmissions
├── heaven-earth
└── four-lessons
```

日柱取自 `FourLessonsResult.dayPillar`，不重复声明对 `calendar` 的直接依赖。快照的 `dependsOn` 固定为按阶段顺序排列的 `heaven-earth`、`four-lessons`。

## 4. 领域模型

三传结果至少表达以下概念：

- `dayPillar`：本次推导所用日柱；
- `plateOffset`：本次推导所用天地盘偏移量；
- `method`：九宗门主名称；
- `subtype`：可空的细分课格；
- `variants`：不替换主细分名的变格，例如杜传；
- `transmissions`：严格按初、中、末排列的三元组；
- `evidence`：有稳定规则编号的结构化证据。

每一传至少包含：

- 传位：初传、中传、末传；
- 地支；
- 六亲；
- 推导摘要；
- 对应证据步骤标识。

九宗门、细分课格、六亲和证据步骤均使用受限联合类型，不接受任意字符串。

## 5. 基础规则表

### 5.1 五行与阴阳

生克判断使用日干或干支本身的五行。第一课的下方是日干，判断生克时不得以日干寄宫地支的五行代替。

比用比较候选上神与日干的阴阳：阳日用阳支神，阴日用阴支神。

### 5.2 课的去重身份

判断四课俱全、三课不备或实际两课时，以以下二元组作为一课的规范身份：

```text
(lookupEarth, upper)
```

这样日干寄宫与日支同位时，即使原始下神一个是天干、一个是地支，也会被识别为同一课。生克判断仍使用原始下神。

### 5.3 天干寄宫与五合

沿用四课阶段已经确定的天干寄宫表。五合固定为：

```text
甲己、乙庚、丙辛、丁壬、戊癸
```

### 5.4 刑、冲、三合与驿马

刑传映射：

```text
寅→巳→申→寅
丑→戌→未→丑
子→卯，卯→子
辰、午、酉、亥自刑
```

六冲使用固定十二支对冲表。

阴日别责使用日支三合局顺行下一支：

```text
申→子→辰→申
亥→卯→未→亥
寅→午→戌→寅
巳→酉→丑→巳
```

反吟无克的驿马表：

```text
申子辰→寅
寅午戌→申
巳酉丑→亥
亥卯未→巳
```

## 6. 总体判定顺序

1. 校验天地盘和四课完整且互相一致。
2. 天地盘十二宫同位时进入伏吟专法。
3. 天地盘整体错开六宫、各宫天地支正冲时进入反吟专法。
4. 其他天地盘进入普通规则链。
5. 三传确定后统一计算六亲。
6. 产生快照前重新校验规范结果和证据完整性。

特殊天地盘只在其专法内部调用所需的贼克、比用或涉害筛选，不再落回普通盘的遥克、昴星、别责或八专。

## 7. 普通规则链

### 7.1 贼克

扫描四课并分别记录：

- 下克上（贼）；
- 上克下（克）。

选择规则：

1. 存在下克上时完全忽略上克下。
2. 唯一下克上直接取受克上神发用，细分为始入。
3. 没有下克上而只有一个上克下，取上神发用，细分为元首。
4. 两类同时出现仍取下克上，并在证据中标记重审。
5. 同一优先类别有多个候选时转入比用。

### 7.2 比用

对当前同类候选比较其上神与日干阴阳：

- 同阴阳者唯一，取其发用；
- 下克上候选保留比用取法；
- 上克下候选细分为知一；
- 候选全部同比或全部不比时，转入涉害。

### 7.3 涉害

对每个候选上神执行“涉地盘归本家”：

1. 找到该上神当前加临的地盘宫。
2. 从当前地盘宫顺行至该上神本家宫。
3. 路径包含起点和终点。
4. 每一宫同时检查地支五行及寄居于该宫的天干五行。
5. 上克下候选累计该上神沿途所克的次数。
6. 下克上候选累计沿途能够克该上神的次数。
7. 克数最多者发用。

克数并列时：

1. 优先取当前加临四孟宫（寅申巳亥）的候选，细分为见机。
2. 无四孟可决时取加临四仲宫（子午卯酉）的候选，细分为察微。
3. 仍完全相等时，只实现原书所述唯一戊辰日干上子发用，细分为缀瑕，别名复等。
4. 其他理论外并列返回 `THREE_TRANSMISSIONS_RULE_UNRESOLVED`，不以数组顺序代替规则裁决。

### 7.4 无上下贼克后的分流

1. 干支同位、去重后实际只有两课时直接进入八专，明确不检查遥克。
2. 其他输入检查遥克。
3. 无遥克且四课俱全时进入昴星。
4. 无遥克且只有三课时进入别责。
5. 仍无法归类时返回规则未决错误。

### 7.5 遥克

遥克只检查第二、第三、第四课上神，重复上神先去重：

1. 先找上神克日干，命中为蒿矢。
2. 没有神克日时再找日干克上神，命中为弹射。
3. 多候选使用比用筛选。
4. 比用仍不能唯一确定时返回规则未决，不擅自套用涉害。

普通方法确定初传后，除后述专法外：

```text
中传 = 初传所临天盘上神
末传 = 中传所临天盘上神
```

## 8. 昴星、别责与八专

### 8.1 昴星

条件：无上下贼克、无遥克且四课俱全。

阳日虎视：

- 初传取地盘酉宫所临天盘神；
- 中传取支上神；
- 末传取干上神。

阴日冬蛇掩目：

- 初传取天盘酉所加临的地盘支；
- 中传取干上神；
- 末传取支上神。

### 8.2 别责

条件：无上下贼克、无遥克且去重后只有三课。

阳日：取日干五合之干的寄宫上神为初传。
阴日：取日支三合局顺行下一支为初传。
中传、末传均取干上神。

### 8.3 八专

条件：干支同位、去重后实际只有两课且无上下贼克。八专不取遥克。

阳日：从干上神起，在十二支顺序中连起点数三位，第三位为初传，即顺移两宫。
阴日：从第四课上神起，在十二支逆序中连起点数三位，第三位为初传，即逆移两宫。
中传、末传均取干上神。

## 9. 伏吟专法

条件：天地盘十二宫全部同位。

### 9.1 有克

- 初传按贼克的下贼优先规则选取；
- 多候选继续使用比用、涉害消歧；
- 主课格为伏吟，细分为不虞；
- 中末传使用刑传，不使用天盘递取。

### 9.2 无克

- 阳日以干上神为初传，细分为自任；
- 阴日以支上神为初传，细分为自信；
- 不取遥克。

### 9.3 刑传与杜传

1. 初传不自刑，中传取初传所刑。
2. 中传不自刑，末传取中传所刑。
3. 初传自刑时，阳日改取支上神、阴日改取干上神为中传，并增加杜传变格。
4. 改取后的中传仍自刑时，末传取中传六冲支，不再取刑。

## 10. 反吟专法

条件：天地盘整体错开六宫，且每宫天地支正冲。

### 10.1 有克

- 初传沿用贼克、比用、涉害的完整消歧；
- 中传取初传所临天盘上神；
- 末传取中传所临天盘上神；
- 主课格为反吟，证据保留实际发用的贼克细分。

### 10.2 无克

无克反吟必须属于：

```text
丁丑、丁未、己丑、己未、辛丑、辛未
```

- 初传取日支驿马；
- 中传取支上神；
- 末传取干上神；
- 细分为井栏。

不属于六日却出现反吟无克时返回规则校验错误。

## 11. 六亲

三传确定后，逐一比较传支五行与日干五行，不按阴阳细分正偏：

```text
生我：父母
我生：子孙
克我：官鬼
我克：妻财
同我：兄弟
```

每一传的六亲证据必须记录日干五行、传支五行、作用方向和结论。

## 12. 证据模型

证据必须是可测试的步骤列表，不使用单一说明字符串替代。步骤按以下阶段组织：

1. 天地盘类型判断；
2. 四课规范身份及去重；
3. 每课上下生克关系；
4. 九宗门候选及排除原因；
5. 比用阴阳筛选；
6. 涉害逐宫路径及累计；
7. 初传最终结论；
8. 中传推导；
9. 末传推导；
10. 三传六亲。

涉害的每一个路径宫必须记录：

- 当前地盘宫；
- 地支及五行；
- 该宫寄居天干及五行；
- 哪个对象构成克；
- 本宫增量；
- 累计次数。

这样 UI 可以完整展示“为什么此候选涉害更深”，校验器也可以拒绝只伪造总数的结果。

## 13. 校验与失败语义

错误代码保持精简：

- `INVALID_THREE_TRANSMISSIONS_INPUT`：上游缺失、失效或互相不一致；
- `THREE_TRANSMISSIONS_RULE_UNRESOLVED`：规则链无法唯一裁决；
- `THREE_TRANSMISSIONS_RESULT_INCOMPLETE`：结果或证据不完整。

结果守卫不能只检查字段类型。它应使用有效天地盘和四课重新执行确定性规则，并比较：

- 日柱和天地盘偏移量；
- 主课格、细分课格和变格；
- 初中末传及顺序；
- 每传六亲；
- 所需关键证据。

任一失败都从 `three-transmissions` 开始失效：保留日历、天地盘、四课，移除旧三传、天将和课体等全部下游快照。

## 14. 审阅界面

采用传统纵列布局。

### 14.1 桌面端

- 页首显示“九宗门 · 三传取法”、日柱、主课格和细分课格。
- 左侧由上至下固定排列初传、中传、末传。
- 每传显示六亲、传支、“待天将加临”占位和推导摘要。
- 右侧显示完整证据。

点击传位后，证据区切换到相关步骤：

- 初传：天地盘分类、四课生克、候选、比用或涉害；
- 中传：递取、刑传或专法；
- 末传：递取、取刑或取冲；
- 各传均附六亲依据。

右侧提供“查看四课”和“查看天地盘”入口，不提供批准或手工改传按钮。

### 14.2 窄屏

按“三传结果、课格摘要、完整证据”纵向排列。关闭证据后，焦点返回刚才选择的传位按钮。交互保持键盘可达，并使用当前项目既有的暗铜、汝窑青与旧金色视觉语言。

## 15. 测试矩阵

### 15.1 规则测试

- 贼克：始入、元首、重审；
- 比用：唯一同比、全部同比转涉害、全部不比转涉害；
- 涉害：克数胜出、见机、察微、缀瑕；
- 遥克：蒿矢、弹射、多候选比用；
- 昴星：阳日虎视、阴日冬蛇掩目；
- 别责：阳日合干、阴日三合前支；
- 八专：阳日顺数、阴日逆数，并断言未执行遥克；
- 伏吟：有克不虞、无克自任、无克自信、初传自刑、次传自刑取冲；
- 反吟：有克、六日无克井栏、非法无克输入；
- 六亲：父母、子孙、官鬼、妻财、兄弟各一例。

优先采用林烽书中给出的完整课例作为固定样本；书中未覆盖的分支使用最小构造夹具，并在测试名中说明规则来源。

### 15.2 契约与集成测试

- 缺失或伪造天地盘、四课依赖；
- 日柱或天地盘与三传快照不一致；
- 合法地支组成但顺序错误；
- 主课格、细分课格、六亲或关键证据被篡改；
- 重算三传时清除天将和课体；
- 三传失败时仅保留有效上游；
- 阶段轨道在有效三传快照产生后推进到天将。

### 15.3 界面与端到端测试

- 三传固定纵向顺序；
- 点击初、中、末传切换对应证据；
- 涉害逐宫证据完整呈现；
- 可返回四课和天地盘审阅；
- 窄屏布局无横向溢出；
- 关闭证据后焦点正确返回；
- 全流程从历法输入运行到三传，并能在已完成阶段间导航。

## 16. 实施约束

- 采用有序纯函数规则链，不引入通用规则引擎。
- 九宗门规则拆为可独立测试的最小判定函数，但不为一次性分支建立多余抽象层。
- 共享的五行、阴阳、寄宫、刑冲合、三合、驿马表应只有一个规范来源。
- 先写失败测试，再实现对应规则。
- 仅修改三传直接涉及的领域、快照接线、审阅 UI 和测试，不顺带重构其他阶段。

## 17. 依据
