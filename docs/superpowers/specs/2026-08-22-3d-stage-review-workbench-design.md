# 大六壬三维阶段回看工作台改版设计

日期：2026-08-22
状态：交互与视觉方案已逐段确认，等待书面规格复核

## 1. 背景与问题

现有产品已经能完成历法、天地盘、四课、三传、天将和复制结课六阶段计算，并在最终课式后提供三维器物播放。然而当前体验存在四个核心偏差：

1. 起课表单强制填写经纬度，但当前规则链固定使用北京时间，经纬度不参与任何计算。
2. 地点被强制要求，实际只承担课式记录作用；同时缺少用户真正关心的“起课事由”。
3. 右侧阶段轨切换六套二维审校页面，三维时间轴只出现在最终课式页面，阶段回看与三维模型完全分离。
4. 页面、模型灯光和模型表面文字过暗、过小；客户旋转镜头后，构件名称无法稳定阅读。

本次改版把产品从“二维规则审校页附带一个最终三维演示”调整为“以三维器物为主舞台的六阶段回看工作台”。

## 2. 成功标准

- 起课表单只保留起课时间、选填地点和必填起课事由，不再出现经纬度。
- 起课完成后默认进入明亮、可读的三维推演工作台。
- 点击任一已完成阶段，模型自动完成“定位、快速累积前序、当前机构分解、停驻观察”。
- 六个阶段分别拥有明确且机械可信的分解姿态，不使用无意义爆炸动画。
- 默认推演文字压缩为阶段名、一句结论和关键结果；完整依据进入按需抽屉。
- 桌面端可显示全部 22 个逻辑构件名称；标签保持屏幕固定字号，引线随水平和垂直镜头移动实时更新。
- 移动端常驻当前阶段 3–6 个标签，并通过底部构件目录访问全部 22 项。
- 页面和模型显著提亮，但仍能区分青铜、铜绿、天青釉与旧金，不出现泛白或高光裁切。
- 三维加载失败时，起课上下文、文字课式和规则依据仍可使用。

## 3. 已确认的产品决策

### 3.1 视觉方向

采用“天光博物馆”方向：

- 页面使用浅暖灰米色背景和半透明暖白面板。
- 模型舞台采用浅暖中心光、青灰外围层次和清晰接触阴影。
- 增加环境补光与轮廓光，使暗部结构可辨，同时保留金属与釉面的反射差异。
- 不继续使用大面积近黑页面与低照度模型展示。

### 3.2 起课输入

起课输入调整为：

- `civilDateTime`：必填，继续按 `Asia/Shanghai` 固定北京时间计算。
- `locationName`：选填，仅进入课式记录，不参与计算。
- `reason`：必填，多行自由文本，去除首尾空白后长度为 1–120 个字符。
- `longitude`、`latitude`：从界面、输入类型、测试夹具和课式流程中移除。

起课事由在主工作台显示两行摘要，在文字课式和复制文本中完整保留。地点为空时不生成“地点：”空行。

### 3.3 推演文字

默认舞台只显示极简字幕：

- 阶段序号与名称。
- 一句阶段结论。
- 一行关键结果。
- “推演依据”入口。

现有详细规则结果不删除，但移入阶段依据抽屉。十二宫矩阵、四课逐项、三传候选与天将排列等长内容只在用户主动展开时出现。

### 3.4 阶段回看

右侧六阶段轨成为三维回看入口，不再默认把中央舞台替换成独立二维审校页。点击阶段后自动执行：

1. 定位到该阶段开始时间。
2. 在短时间内重现已完成的前序结构。
3. 播放当前机构的结构分解动画。
4. 停在可观察姿态并把镜头控制交还用户。

保留“上一阶段”“下一阶段”“重播本阶段”“推演依据”和“文字课式”入口。原始连续时间轴仍可作为高级控制，但不再是普通客户理解阶段的唯一方式。

### 3.5 模型标注

采用参考图式的屏幕空间标注，而不是仅放大模型表面贴图：

- 模型表面铭牌继续保留器物真实性。
- 每个逻辑构件增加稳定三维锚点。
- 标签卡固定在画面四周，始终朝向屏幕。
- SVG 细引线连接屏幕标签卡与投影后的三维锚点。
- 锚点与引线在每个渲染帧根据当前相机和构件世界矩阵重新计算。
- 背向或被其他几何遮挡的构件使用淡化虚线，名称不消失。
- 标签槽位使用稳定排序、碰撞避让和切换滞后，避免客户拖动镜头时标签跳动。

桌面标注最小字号为 14px，移动端为 16px。引线保持约 1px 视觉宽度，不使用粗重边框或大面积发光。

## 4. 页面结构

### 4.1 起课前

起课页只显示三个字段：

1. 起课时间。
2. 地点，标记为“选填，仅用于记录”。
3. 起课事由，标记为必填并显示 120 字计数。

主按钮文案改为“开始推演”。错误就地显示；事由为空或超过 120 字时不提交。

### 4.2 起课后桌面工作台

桌面使用三栏结构：

- 左侧：折叠后的起课上下文，包含时间、选填地点、事由摘要和“重新起课”。
- 中央：明亮三维模型舞台、动态标注层、极简字幕与回看控制。
- 右侧：六阶段回看轨。

中央舞台提供三种标注密度：“全构件”“当前阶段”“隐藏标注”。默认使用“全构件”。

### 4.3 移动端

移动端不强制横屏：

- 起课上下文折叠为顶部摘要。
- 中央保持可上下、左右拖动的三维舞台。
- 画面常驻当前阶段 3–6 个大标签。
- 底部抽屉列出全部 22 个逻辑构件；点击任一构件后聚焦模型并显示其动态引线。
- 六阶段轨改为横向阶段条或底部抽屉，不与构件目录同时占满画面。

## 5. 六阶段结构分解

### 5.1 历法与月将

- 校时简沿后导轨升起。
- 读数层轻微前倾，导轨与止挡短暂显露。
- 镜头停在后上方近景。

### 5.2 天地盘加临

- 天盘先抬升，显露中心轴承与十二档定位环。
- 天盘回落并旋转到实际锁位。
- 地盘始终固定。
- 镜头停在正上方微倾角度。

### 5.3 四课生成

- 四枚课翼左右依次推出。
- 上下神读数片逐枚抬升。
- 燕尾导轨和止挡保持可见。
- 镜头停在前上方全览。

### 5.4 三传取法

- 前桥沿正前方推出。
- 初传、中传、末传依次错层拉开。
- 方向榫与实体承托桥保持可见。
- 镜头停在前方低角度。

### 5.5 天将排列

- 十二将印分批升起。
- 底部链轨显露并按实际结果演示顺布或逆布。
- 将印最终回落并锁定对应宫位。
- 镜头停在环形斜俯视角度。

### 5.6 复制结课

- 实体机构保持完整，不伪造机械复制。
- 四课、三传和天将生成半透明来源副本。
- 来源引线汇聚成最终课式后淡出。
- 镜头回到整体英雄视角。

## 6. 交互与相机

- 水平拖动允许 360° 环绕。
- 垂直拖动把俯仰角限制在 20°–75°。
- 阶段自动镜头只负责进入推荐观察角度。
- 客户开始拖动后，当前自动镜头立即停止；机构动画可以继续。
- 分解动画结束后不自动抢回镜头。
- “重置视角”恢复当前阶段的推荐角度，而不是总是返回同一全局相机。
- `prefers-reduced-motion` 下取消长距离自动环绕，直接切到分解后的最终姿态；标注投影和信息不减少。

## 7. 数据与组件边界

### 7.1 输入与课式上下文

`CourseInput` 调整为：

```ts
interface CourseInput {
  civilDateTime: string;
  timeZone: "Asia/Shanghai";
  locationName?: string;
  reason: string;
  corrections: Partial<{
    yearPillar: StemBranch;
    monthPillar: StemBranch;
    dayPillar: StemBranch;
    hourPillar: StemBranch;
    monthGeneral: EarthlyBranch;
    divinationHour: EarthlyBranch;
  }>;
}
```

`CourseResult.context` 同步增加 `reason` 并把 `locationName` 改为可选。地点和事由属于最终课式投影依赖；其变化只应使 `course` 快照失效，不改变历法、天地盘、四课、三传或天将结果。

课式 guard、快照匹配、序列化文本和测试夹具必须同时覆盖地点缺失、事由变化和非法事由。

### 7.2 三维阶段定义

新增统一的阶段展示定义，作为阶段轨、字幕、自动相机和分解姿态的共同来源：

```ts
interface ArtifactReviewStage {
  id: RuleStageId;
  startTimeMs: number;
  settledTimeMs: number;
  caption: ArtifactStageCaption;
  cameraPreset: ArtifactCameraPreset;
  annotationIds: readonly ArtifactAnnotationId[];
  decomposition: ArtifactDecompositionPose;
}
```

阶段轨不得自行维护第二份时间或文案表。

### 7.3 标注层

新增独立的 `ArtifactAnnotationLayer`，位于 Three.js canvas 上方：

- 输入为相机、画布尺寸、22 个标注描述符及其世界坐标。
- 输出为屏幕锚点、标签槽位、遮挡状态和 SVG 引线路径。
- `ArtifactSceneController` 只提供节点世界位置、相机和聚焦能力，不负责创建 HTML 标签。
- 标注布局引擎是纯函数，便于在无 WebGL 环境下测试投影、避让和稳定排序。

22 个逻辑标注包括：校时简、固定地盘、旋转天盘、四枚课翼、初中末三传和十二天将。复制结课的来源副本属于阶段视觉，不增加伪造的实体构件标签。

## 8. 灯光与可读性

页面与模型灯光一起调整，避免只提高 CSS 亮度：

- 页面背景从近黑改为浅暖灰米色。
- 舞台背景中心保持暖白，外围过渡到低饱和青灰。
- 环境填充提高到主光视觉贡献的约 45%–55%。
- 轮廓光用于分离天盘、课翼、前桥和将印，不形成明显光晕。
- 保留接触阴影和凹槽暗部，但暗部结构必须在普通笔记本屏幕上可辨。
- 天青釉、青铜和旧金在整体镜头中仍须依靠反射与粗糙度区分，而不只是颜色区分。

最终数值以桌面和移动端截图审查为准，不以单一曝光参数作为验收结果。

## 9. 错误与降级

- 表单错误不清空已填写的时间、地点或事由。
- 三维资源加载失败时显示文字课式与完整起课上下文。
- 标注层失败时不影响 Three.js 场景播放；保留极简字幕和构件目录。
- WebGL context loss 继续切换到文字课式，不要求重新起课。
- 缺少某个预期锚点时记录开发错误，并只隐藏该标签，不猜测坐标。
- 移动端性能不足时优先减少阴影与后期效果，不减少规则构件和构件目录。

## 10. 无障碍

- 阶段轨、标注密度、构件目录和回看控制均使用真实按钮。
- 当前阶段使用 `aria-current="step"`。
- 构件目录提供与屏幕标签相同的文本信息，不依赖引线或颜色才能理解。
- 键盘选择构件后，焦点保持在目录项；模型聚焦不夺取 DOM 焦点。
- 屏幕阅读器通过阶段字幕和构件目录读取结果，不读取 SVG 引线。
- 减少动态模式仍保留所有最终结构、标签和课式事实。

## 11. 验收与测试

### 11.1 输入与数据

- 经度和纬度不再出现在表单、输入类型或提交结果中。
- 地点为空可以成功起课，序列化文本不输出空地点行。
- 事由为空、纯空白或超过 120 字时显示稳定错误。
- 事由完整进入 `CourseResult`、文字课式和复制文本。
- 修改地点或事由只使最终 `course` 快照失效。

### 11.2 阶段回看

- 六个阶段按钮都能触发正确的时间、字幕、相机预设和分解姿态。
- 前进、后退、重播和任意跳转得到相同最终节点变换。
- 客户拖动后自动镜头停止，机构动画继续且结果不变。
- 减少动态模式直接到达同一最终分解姿态。

### 11.3 动态标注

- 桌面标注目录恰好包含 22 个唯一逻辑构件。
- 水平环绕与 20°–75° 俯仰时，引线端点始终等于构件锚点的当前屏幕投影。
- 标签卡不随模型旋转，字号不随相机距离缩小。
- 标签碰撞避让后不互相覆盖，连续小幅拖动不产生槽位抖动。
- 遮挡状态在相机越过构件前后关系时更新。
- 移动端画面只常驻当前阶段标签，但底部目录始终包含全部 22 项。

### 11.4 视觉与性能

- 桌面和 390×844 移动视口没有页面级水平溢出。
- 页面、模型整体、结构分解近景和动态标注各保存一张视觉验收图。
- 深色青铜结构、刻槽和活动件在验收图中可辨；高光不裁切。
- 标注更新不引起明显布局抖动；性能基准仍满足桌面 60 FPS、移动端 30 FPS。
- 生产构建、单元测试、组件测试、GLB 校验和 Playwright E2E 全部通过。

## 12. 分段实施与确认门槛

为了避免无效更新，实现必须按以下顺序分段交付；每段完成后提供可运行预览和截图，经用户确认后才进入下一段：

1. 输入与明亮工作台外壳：移除经纬度，加入选填地点和必填事由，完成页面提亮。
2. 统一阶段轨与极简字幕：阶段按钮控制三维时间点，详细依据进入抽屉。
3. 六阶段结构分解：逐阶段实现确定性分解姿态和推荐镜头。
4. 桌面动态标注：完成 22 锚点、屏幕投影、细引线、遮挡和避让。
5. 移动端构件目录：常驻阶段标签，底部目录覆盖全部 22 项。
6. 完整回归与性能收尾：修复资产流水线红灯、拆分首屏三维包、运行完整交付门槛。

任何阶段未获确认时，只调整当前阶段，不提前改动后续视觉或交互。

## 13. 本次不包含

- 新增术数规则、综合断语、应期或神煞体系。
- 使用经纬度计算真太阳时或地方时。
- 为复制结课伪造不存在的机械机构。
- 重建现有 Blender 母版的整体造型语言。
- 与三维工作台无关的通用组件库或主题系统重构。
