# 大六壬小工具离线包设计

## 目标

在不改变现有 GitHub Pages 网站及其高精度 GLB 模型的前提下，新增一套可上传到小红书小工具容器的离线 ZIP 构建。小工具保留完整起课计算、可旋转三维模型、文字课式、四课三传、十二宫方盘和课式图片保存。

最终 ZIP 必须符合 `minitool-zip-builder` 1.6.0：根目录包含 `index.html`，只含允许的静态文件类型，不联网，不使用模块脚本、WASM、Worker、剪贴板、下载链接或系统长按菜单，包体不超过 10 MiB。

## 构建隔离

- 保留现有 `src/main.tsx`、网站构建和 GLB 资源路径，不改变线上版本行为。
- 新增小工具专用入口、样式和 Vite 配置，构建到独立目录。
- 小工具复用现有领域计算模块、输入类型和课式结果类型，不复制或改写大六壬业务规则。
- 最终脚本转译到 ES2017 / Chrome 61，并产出单个经典 IIFE 脚本；HTML 不包含 `type="module"`。

## 小工具界面

小工具保留两个明确分离的结果子页面：

1. 三维推演：程序化玉盘、天地盘旋转和十二神将展示。
2. 文字课式：四课、三传、十二宫方盘和课式图片保存。

起课输入在首屏完成。生成结果后进入三维推演，可在顶部切换到文字课式；提供重新起课入口。界面沿用现有深青铜、汝窑青和旧金色视觉语汇，但小工具使用 Chrome 61 可用的 Flex/Grid 基线样式，不依赖 Flex gap、`clamp()`、逻辑属性或现代选择器完成核心布局。

## 程序化三维模型

小工具不读取 `.glb`、KTX2 或 WASM。模型由包内 Three.js 核心和运行时几何生成：

- 方形玉质底座与地盘；
- 可旋转天盘及十二地支；
- 十二块彼此分离的神将玉块；
- 四颗浅玉珠；
- 一张不超过 1024×1024 的包内 JPEG 十二生肖地盘纹理；
- 基于低成本标准材质、灯光渐变和少量程序化颜色变化表现玉质，不使用实时阴影、后处理或反射探针。

天地盘采用现有课式 `offset` 和十二宫数据驱动。触摸与鼠标统一使用 Pointer Events；单指旋转、双指缩放，桌面鼠标拖拽旋转和滚轮缩放。相机距离和俯仰角限制在可读范围。

资源预算：DPR 默认不超过 1.5，低档为 1；drawing buffer 不超过约 200 万像素；三角形不超过 50k；draw call 不超过 50；只保留一张 1024 纹理。页面隐藏时暂停动画；持续慢帧时降到 DPR 1；WebGL 初始化或 context 失败时切换到文字课式，不循环重试。

## 课式图片保存

小工具不包含浏览器剪贴板和 `a[download]`。文字课式图片由 Canvas 2D 根据 `CourseResult` 直接绘制为 PNG data URI，避免 `html-to-image` 的资源抓取逻辑。

用户点击“保存课式图片”后：

1. 生成完整 `data:image/png;base64,...`；
2. 调用 `window.xhs.miniTool.writeTempFile({ data })`；
3. 使用返回的 `filePath` 调用 `saveImageToPhotosAlbum({ filePath })`；
4. 显示保存成功或包含可行动提示的失败状态。

若 JSBridge 不存在（例如普通浏览器预览），按钮显示“请在小工具容器内保存”，不调用被禁 API。

## 离线资源与打包

- 小工具构建目录仅保留 `.html`、`.css`、`.js`、`.jpg`/`.png` 等规范允许的类型。
- 所有资源使用 `./` 相对路径；无外部 URL、`<base>`、iframe、自建 CSP 或内联脚本。
- ZIP 直接压缩构建目录内容，使 `index.html` 位于根目录。
- 产物写入 `artifacts/daliuren-minitool.zip`，构建目录写入 `artifacts/daliuren-minitool/`。

## 校验与交付

一次最终校验流水线依次执行：

1. 小工具生产构建；
2. 静态扫描禁止 API、模块脚本、绝对/外部资源路径和禁止文件类型；
3. 检查经典脚本语法目标与 HTML 入口；
4. 检查模型预算、JSBridge 参数和 WebGL 降级代码；
5. 使用 Skill 的 Python 审计脚本审计构建目录；
6. 打包 ZIP；
7. 再审计 ZIP、检查根目录 `index.html` 和 10 MiB 硬门禁。

没有小红书 PC 模拟器或真机运行数据时，交付摘要明确标记：Chrome 61 CSS 兼容性、真机 JSBridge、模型帧率和真机性能均未实测，不宣称真机验收通过。

## 非目标

- 不把现有 GLB 改后缀或编码进 JS/JSON/图片规避门禁。
- 不修改现有网站三维模型、网站图片复制流程或 GitHub Pages 部署。
- 不在本次工作中重新设计大六壬算法或课式数据结构。
