# 大六壬天盘固定字表 v1

## 1. 适用范围

本表只定义中央圆形天盘的固定铭文，不包含地盘十二生肖、十二天将、四课、三传、六亲、空亡或课体。

固定层级由中心向外排列：

1. `H0` 中心转轴：无文字。
2. `H1` 北斗七星：七个星点；星名为低对比度可选铭文。
3. `H2` 二十八宿：二十八个单字，固定顺序。
4. `H3` 十二月将：十二个双字名称，与地支一一绑定。
5. `H4` 天盘十二支：十二个单字，是最高视觉层级。
6. `H5` 旋转轮缘：只有刻度，不增加文字。

## 2. 统一排版口径

- 字体：`Noto Serif CJK SC`，文件为 `assets/daliuren/fonts/NotoSerifCJKsc-Regular.otf`。
- 字形：使用项目现有简体中文口径，不混用繁体、异体字或图片生成文字。
- 方位：上南、下北、左东、右西。
- 十二支角度：以画面正上方为 `0°`，顺时针为正方向。
- 环形文字：文字随实体天盘旋转；单字采用径向排布，字头朝盘外。
- `H4` 天盘十二支：青金/石青色珐琅，最高对比度。
- `H3` 十二月将：朱砂色珐琅，中等对比度。
- `H2` 二十八宿、`H1` 星名：浅金或暖灰浅刻，低对比度。

## 4. H2 二十八宿

### 4.1 固定定位规则

- 每宿占一个等宽槽位，共 `28` 槽。
- 每槽角宽：`360° / 28 = 12.857142857°`。
- `角`从画面左侧正东位置开始。
- 沿逆时针方向排列，即东方青龙 → 北方玄武 → 西方白虎 → 南方朱雀。
- 角度公式：`angle = (270° - ringIndex × 360° / 28 + 360°) mod 360°`。

## 6. 禁止混入的固定文字

以下文字不属于本版天盘固定字表，不得加入常驻环带：

- 十二天将：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后。
- 四课、初传、中传、末传、六亲、空亡、九宗门、课体名称。
- 地盘十二生肖名称及现代说明文字。

## 7. 校验清单

- `H4` 必须恰好 `12` 个单字，且包含 `子丑寅卯辰巳午未申酉戌亥` 各一次。
- `H3` 必须恰好 `12` 个双字名称，且每个名称与对应地支绑定。
- `H2` 必须恰好 `28` 个单字，四象各 `7` 个。
- `H1` 必须恰好 `7` 个星点；星名若显示，必须恰好 `7` 个。
- 不得使用生成式图片中的伪字作为模型贴图或雕刻来源。
